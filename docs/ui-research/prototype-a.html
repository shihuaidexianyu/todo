一个完整的来回。

从记录，到安排，再到完成。这一轮延续你选定的 A 方向，重点补齐页面之间的衔接与真实状态。

建议按这个顺序体验

  1. 点击加号，写下一件事，设置今天截止。
  2. 展开标签，选中工作，再保存。
  3. 进入标签，展开工作，打开刚才的任务。
  4. 把安排改为明天，清除截止，再去“之后”查看。
  5. 完成任务，到“已完成”查看；也可以撤销。
  6. 搜索“中文字体”，查看备注命中片段。

细节已经连接起来

  • 任务只有一份，多视图同步。
  • 标签原地展开；新建继承当前展开标签。
  • 搜索关键词和精确标签筛选可分别清除。
  • 关闭脏草稿可继续、放弃或保存。
  • 保存失败保留输入，取消模拟后可重试。
  • 结束一天只隐藏今天列表，可随时重新展开。
