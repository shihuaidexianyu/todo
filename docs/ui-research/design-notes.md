# 第一轮视觉方向稿

已选定 A。[查看 A 方向交互原型](prototype-a.html)。下文保留第一轮比较依据。

[打开 A/B 高保真预览](design-comparison.html)

两组使用相同的中文任务、相同顺序和相同交互结构，比较范围为今天页、新建面板，以及新建面板中的键盘、标签和截止状态。A 为推荐方向；B 用于比较更强的色彩与形状表达。

| 对比项 | A：克制精致 | B：轻快现代 |
|---|---|---|
| 主体 | 暖白、墨色文字、蓝色主要动作 | 冷白、靛蓝主要动作 |
| 页头 | 纯排版，减少装饰 | 小型日期图形，增强辨识度 |
| 完成控件 | 柔和方形 | 圆形 |
| 标签 | 弱化的文字信息 | 小面积浅色底 |
| 添加 | 紧凑加号按钮 | 带“记一件事”文字的按钮 |
| 适合的感觉 | 平静、耐看、内容突出 | 轻快、动作清楚、较活跃 |

今天页省略重复的“安排今天”，保留截止和提醒文字；仅在确实存在不同时间组时显示分组标题。“结束一天”位于列表末尾，菜单保留入口。新建面板以标题为主，选中当天截止后在原位置表达状态，标签在面板内展开，保存成功直接回到列表。

预览中可操作：两页切换、深色、键盘示意、任务完成/恢复、完成列表展开、标题输入、工作标签选择、当天截止设置/清除、保存与关闭。两组同步样例变化，方便同条件比较。未展开的入口明确提示下一轮范围，不伪装成已实现。

该文件为自包含 HTML，无外部字体、脚本或网络依赖，不接触 Android 数据库。键盘是视觉示意，不能用于判断真实 IME 稳定性。浏览器字体和 Android 系统字体存在差异，HTML 像素也不等于已验证的 Android dp；实际触控范围、系统返回、字体缩放和键盘动画在后续原生实现阶段验证。

已检查脚本语法与重复 HTML ID。当前环境没有可用的浏览器自动化连接，尚未完成浏览器实屏截图验收；预览不应当作已通过 Android 视觉验收的成品。
