# A 方向交互原型

视觉方向已确认采用 A：暖白、墨色文字、克制的蓝色、任务内容优先。后续原生实现沿用此方向，不再继续 A/B 风格探索。

[打开交互原型](prototype-a.html)

## 页面与状态

- 今天：截止分组、任务完成/撤销、已完成折叠、编辑、新建。
- 收件箱：无安排任务；截止和标签不影响归属。
- 标签：系统汇总与自定义标签分区，原地展开，新建标签，当前展开标签作为新增默认值。
- 搜索：关键词、待办/全部、精确标签筛选、备注命中片段、清空、返回时保留查找状态。
- 之后：未来安排或截止日期分组；逾期任务继续留在今天。
- 已完成：查看、恢复与编辑；样例仅使用“最近完成”分组，原生实现仍需按真实完成日期分组。
- 编辑：标题、备注、安排和截止、标签原地选择；未保存退出确认；失败保留草稿并重试。
- 收尾：直接隐藏今天列表；重新展开后恢复显示，不修改任务。右上角直接进入设置。

键盘是视觉占位，不模拟真实输入法。样例日期固定为 2026-09-11。任务保存在页面内存，刷新即重置，不会读写 Android 的用户数据。完整提醒配置、时分选择、权限、设置和备份由后续原生实现承接，浏览器原型不假装执行这些平台能力。

## 验证

`node --check prototype-a.js` 通过。`node verify-prototype.cjs` 检查保存失败保留草稿、成功创建、完成撤销、改期、备注命中高亮、精确标签筛选、放弃编辑、隐藏/重新展开不修改任务等状态流。

这些检查不包含浏览器视觉渲染或真实输入法。当前没有可用的浏览器自动化连接，尚未完成实际浏览器截图验收。Android 阶段需继续验证系统返回、中文 IME、字体缩放、对比度和 48 dp 触控范围。
